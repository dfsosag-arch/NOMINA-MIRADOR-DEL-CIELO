# Nómina – Cafetería El Mirador del Cielo

Aplicación web para administrar empleados, asistencia diaria, créditos, anticipos y liquidación mensual.

## Desarrollo

```bash
npm install
cp .env.example .env.local
npm run dev
```

El esquema PostgreSQL inicial está en `supabase/schema.sql`. Configura Supabase antes de usar datos reales. Esta herramienta es para control interno y no sustituye un sistema legal de nómina laboral colombiana.
